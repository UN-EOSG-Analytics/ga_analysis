# 2025년 제출 PDF 재대조 및 정리

## 결론

`data/raw/`에 다시 들어온 **PDF 218개와 인덱스 1개는 기존 ZIP 보관본과 동일한 파일**이다. 새 국가 발언을 추가하거나 전사 본문을 교체할 근거는 확인하지 못했다. 마지막 날을 포함해 비교 근거를 갱신하고, 발견한 내용 차이를 분석 입력의 검토 메타데이터로 보완했다. 삭제 결과와 파일별 해시는 [정리 기록](raw_2025_cleanup.json)에 기록한다.

| 항목 | 결과 | 처리 |

마지막 날 비교 대상: 북한, 덴마크, 에리트레아, 말라위, 네팔, 니카라과, 몰도바, 세인트루시아, 동티모르, 바누아투, 잠비아. 이 11개국이 마지막 날 전체라는 뜻은 아니다. 마지막 날 전사에는 회원국 주요 발언 17개가 있다.

## 분석 전에 확인할 내용 차이

**세인트빈센트그레나딘 (`2025_VCT`)**: 제출 PDF의 물리적 16페이지(인쇄된 쪽 번호 15)에 대괄호로 묶인 AI 규제·총회 역할 문단이 있다. 전사의 해당 위치는 기후변화 부분에서 허리케인 피해 부분으로 넘어가며 이 문단은 없다. 전사 앞부분에는 별도의 `artificial intelligence` 언급이 있으므로 국가의 AI 언급 자체가 새로 발견된 경우는 아니다.

이 차이가 실제 발언 생략인지 자동전사 누락인지는 현재 두 문서만으로 확정할 수 없다. 해당 추가 문단의 주제·UN 역할을 최종 집계하려면 음성 또는 공식 속기록으로 실제 낭독 여부를 확인한다. 미확인 상태에서는 해당 판정을 `Uncertain/Pending`으로 유지한다. 준비된 원고를 전사에 붙이거나 PDF를 두 번째 국가 발언으로 세지 않는다.

- [PDF 인용과 전사 위치 근거](pdf_2025_review_evidence.json)
- [재생성 시 유지할 검토 표시](../../config/source_review_notes.json)
- 현재 활성 등록부, 추출본 등록부, `output/pipeline/speeches.jsonl`의 해당 행에 같은 검토 표시를 반영했다. 국가별 원문 JSON과 구절 텍스트·출처 위치·해시는 유지했다.

쿠바·나미비아·포르투갈에서 PDF의 `AI`와 전사의 `artificial intelligence` 표현 차이는 해당 문맥을 읽어 확인했다. 이 차이를 AI 언급 누락으로 처리하지 않는다. 이탈리아 PDF는 화면상 2025년 제80차 총회 자료이며, 첫 페이지의 `2024`는 Global Peace Index 연도다.

## 비교 범위와 재현 근거

- [파일별 비교표 CSV](pdf_2025_comparison.csv): 국가, 언어, 비교 상태, 양방향 5단어열 겹침 비율, 해시, ZIP 파일과 내부 경로.
- [페이지별 추출 텍스트와 후보](pdf_2025_comparison_detail.json), [집계 JSON](pdf_2025_review_summary.json).
- [투입 파일 목록](raw_2025_inventory.json), [ZIP 대조·삭제 기록](raw_2025_cleanup.json).

기존 페이지 추출본은 원본 PDF 해시, 전체 추출 캐시 해시, 페이지 수, 페이지별 원본 해시가 일치할 때만 재사용했다. 해당 캐시는 `archive/retired_materials.zip`의 `cache/extraction/selected_pages.jsonl`이며, SHA-256은 `044e7133e52ce2cdfd6b79f9f62ebc7eac43248047fd30faa2cb7f0d0b148bb7`이다. 원본 파일은 비교표에 적힌 ZIP 내부 경로에 보존한다.

단어열 겹침은 공백·대소문자 등을 정규화한 텍스트 비교 지표다. 낮은 비율만으로 잘못된 전사라고 판단할 수 없다. 제출 영어 번역과 현장 영어 통역은 표현이 다를 수 있고 준비 원고와 실제 발언도 다를 수 있다. 예를 들어 파푸아뉴기니는 전사가 제출 PDF보다 훨씬 길어 PDF로 일괄 교체하지 않았다.

AI 후보 검색은 `artificial intelligence`, 독립 단어 `AI`, `machine learning`, `generative`, `deepfake(s)`, `large language model(s)`를 사용했으며 검색 전에 유니코드 합자 등을 정규화했다. 영어 비교 가능 PDF 중 44개국에서 후보가 나왔고, 이들 전사에도 검색어 후보가 있었다. **이는 AI 내용 전체의 일치나 주제 검토 완료를 의미하지 않는다.** 모든 문장의 의미 대조와 음성 검증은 수행하지 않았으며 기존 ASR 정확성 미검증 표시를 유지한다.

이번 작업에서는 API 호출·임베딩·분류·보고서 통계 산출을 실행하지 않았다. 보완한 것은 비교 근거와 검토 메타데이터다.
