# DB 재점검 결과

**확보된 1,888개 발언의 구조·원본 연결은 정상이다. 전체 국가–연도의 완전 확보나 본문의 모든 문장이 영어라는 뜻은 아니다.** 이번 점검은 원문과 분석 본문을 변경하지 않았다.

## 확인 결과

| 점검 | 결과 |
|---|---|
| 국가–연도 입력 | 1,888개, 모두 영어 판본으로 등록 |
| 공통 분석 구절 | 49,912개 |
| 입력의 원본 형식 | 공식 영어 PV 1,528개 발언 + ASR JSON 343개 + ASR TXT 17개 |
| 해시·원본 위치·추출 캐시·본문 보존·중복 | 오류 0건 |
| 공식 PDF 직접 대조 | 47,321개 추출 문단을 실제 PDF 페이지·블록·좌표와 비교, 불일치 0건 |
| 자동전사 직접 대조 | JSON pointer/TXT 줄 범위의 실제 원문과 추출 문단 일치 |
| 과거 영어 제출문 부재 목록 | 회원국 416건 모두 영어 속기록 연결. 팔레스타인 1건은 회원국 분석 범위에서 제외 |
| 언어 점검 | 전체 발언 수준의 비영어 본문 의심 사례 없음. 문단 수준의 비영어 구절 4곳 확인 |
| 193개 회원국 × 10년 중 입력 없는 조합 | 42건. 실제 미발언과 미확보의 전수 구분은 미완료 |
| 발언자 직급 | 활성 국가별 입력·등록부·정규화 입력에서 제거 확인 |

416건은 **이전 목록에 있던 국가–연도의 영어 대체 원문이 확보됐다는 확인**이다. 비영어 제출문과 영어 전사의 문장별 번역 일치를 검증한 것은 아니다. 이전 언어 목록은 한국어 부분이 이미 깨져 있었으나 연도·영문 국가명은 읽을 수 있어 그 목록을 대조했다.

## 남아 있는 언어 예외

| 국가–연도 | 원본 위치 | 확인 내용 |
|---|---|---|
| 뉴질랜드 2019 | `A_74_PV_4_EN.pdf` 46쪽, 문단 1 | 마오리어 인사. 다음 문단에 영어 설명. 특이한 철자도 공식 PDF 화면에 존재 |
| 카자흐스탄 2020 | `A_75_PV_6_EN.pdf` 18쪽, 문단 11 | 카자흐어 인용. 같은 문단에 영어 번역 병기 |
| 뉴질랜드 2022 | `A_77_PV_10_EN.pdf` 35쪽, 문단 1 | 마오리어 인사. 다음 문단에 영어 인사·설명 |
| 파키스탄 2025 | `UNGA2025_day4_EN_ASR.json`, `/transcript/data/5/paragraphs/0` | 로마자로 전사된 아랍어 도입 낭독. 뒤에 짧은 영어 구절이 있으나 번역 완전성 미확인 |

이 네 곳을 임의로 번역하거나 삭제하지 않았다. 엄격한 영어 전용 분석을 적용할 때는 해당 구절의 처리 방침을 남겨야 한다. 영어 설명이 있는 경우도 원어의 완전한 문장별 번역을 확인한 것은 아니다. 확인하지 않은 내용을 AI 미언급으로 자동 판정하지 않는다. [원문·인접 문단 확인 기록](language_exception_review.json).

언어 선별은 영어 판본 표시와 영어·프랑스어·스페인어·포르투갈어 기능어 비율 및 문자체계를 사용했다. 전체 발언과 40단어 이상 문단을 선별하고 발견된 네 곳을 원문과 함께 읽었다. 짧은 외국어 인사까지 모두 찾아냈거나 전문 언어 검증·자동전사 원음 검증을 마쳤다는 의미는 아니다.
