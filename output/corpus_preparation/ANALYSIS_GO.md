# 분석 시작 판단 — GO

이 문서는 코퍼스 준비 판단이다. 이후 구현한 전체 분석 프로그램의 실행·검증·비용 상태는 [ANALYSIS_WORKFLOW.md](../../docs/ANALYSIS_WORKFLOW.md)와 `output/workflow_readiness.json`을 따른다.

**현재 DB로 문맥 검토와 분석을 시작해도 된다.** 2026년은 Day 1–5 부분 자료로 표시한다. 이 판단은 최종 통계·보고서가 검증 완료되었다는 뜻은 아니다.

## 중복과 구조 점검

| 항목 | 최종 확인 |
|---|---:|
| 활성 분석 발언 | 1,888건 |
| 고유 국가–연도 | 1,888건 |
| 분석 구절 | 49,912개 |
| 공식 영어 속기록 | 1,528건 |
| 영어 자동전사 | 360건 |
| 제출 국가별 PDF가 별도 분석 행에 포함된 수 | 0건 |
| 원문·추출본 해시, 위치, 본문 보존 등 무결성 오류 | 0건 |
| 남은 바이트 중복 PDF 그룹 | 0건 |

공식 회의 PDF 하나에 여러 국가의 연설이 들어 있는 것은 정상이다. 국가별로 분리한 본문만 등록한다. 제출 PDF는 대조 근거이며 전사에 더해 두 번째 관측치로 집계하지 않는다. 활성 등록부·정규화 입력의 중복 국가–연도와 source ID, 구절 ID도 검사한다. 중복 대표본 등록과 중복 검색 입력은 오류로 차단한다. 단어 적중이 여러 번 있어도 국가–연도별 최종 OR 집계는 한 번이다.

근거: [이번 최종 점검 JSON](analysis_go.json), [무결성 결과](input_integrity.json), [제출 PDF 대조](pdf_2025_review.md).

## 2026년 Day 6만 들어오면 되는가?

**현재 확인된 추가 수집 대상은 2026년 Day 6 전사다.** 현재는 Day 1–5의 171개국이며 Day 6 파일은 없다. 2025년은 마지막 날 17개 발언을 포함해 189개국이다.

Day 6 입수 후 다음을 수행한다.

1. `data/unga_general_debate_verbatim_en/automatic_transcripts_unofficial/`에 원본과 출처 정보를 보존한다.
2. `python -m unga_analysis prepare`로 국가별 분리·중복 차단·입력 갱신·무결성 검사·후보 검색을 다시 수행한다.
3. 추가 국가, 발언 시작·끝, 답변권·의장 발언 제외를 확인하고 실제 참가 명단과 맞춘다.
4. 분석 워크플로우는 Day 1–6 원본에서 실제로 분리·입력된 자료를 확인한 뒤 수집 조건을 충족한 것으로 처리한다. 실제 참가 명단의 완전 대조를 의미하지는 않으며 보고서에 해당 한계를 남긴다.

193개국 × 10년과의 차이 42건은 현재 입력이 없는 국가–연도다(2017–2025년 20건, 2026년 22건). 모두 누락 파일이라는 뜻은 아니며 실제 미발언 여부는 전체 참가 명단과 별도 확인이 필요하다. 따라서 “Day 6을 추가하면 모든 연도의 완전성까지 입증된다”고 단정하지 않는다. 미확보·미참가 구분이 끝나기 전에는 이를 AI 미언급으로 채우지 않는다.

## AI 유의어·관련 표현

기존 PDF 대조용 검색과 별도로 **분석용 로컬 검색 모듈을 구현하고 전체 입력에서 실행했다.** [검색어 설정](../../config/ai_search_terms.json), [검색 결과](../screening/README.md)를 참조한다.

| 검색 범위 | 예시 | 판정 방식 |
|---|---|---|
| AI 명시 표현 | AI, A.I., Artificial Intelligence, Generative AI, GenAI | 후보를 찾고 문맥 검토 |
| 초지능·범용 지능 | Superintelligence, Super Intelligence, Super-intelligence, Artificial General Intelligence | 표현별 근거를 보존하고 문맥 검토 |
| 약어 | AGI, ASI, SI, LLM, ML 등 | 문맥에 따라 다른 의미일 수 있어 별도 검토 |
| 관련 기술·개념 | Machine Learning, Deep Learning, Neural Networks, Large Language Models, Foundation Models, Deepfakes | AI와의 관련성을 검토하며 동일한 뜻으로 자동 통합하지 않음 |
| 간접 표현 | Algorithms, Robotics, Digital Compact 등 | AI 확정 표현과 분리한 누락 점검 후보 |

대소문자·공백·하이픈·줄바꿈·유니코드 합자·구절 경계를 처리하며 원래 근거 위치를 보존한다. `said`, `AIDS`, `AIIB`, 군사 정보의 `intelligence`, 보통 문장의 `as I` 등을 AI/ASI로 오인하는 대표 사례도 점검했다. 유의어·출처 보존·중복 차단·미적중 Pending 처리 테스트 8개가 통과했다.

모든 우회 표현과 자동전사 오류를 검색어만으로 100% 포착한다고 보장할 수 없다. 검색 결과는 최종 통계가 아니며 문맥 검토와 미적중 발언의 누락 점검이 필요하다. 모든 AI·주제 레이블은 Pending으로 유지했다.

## 분석 중 유지할 검토 사항

- **2025년 세인트빈센트그레나딘:** PDF 추가 AI 규제 문단의 실제 낭독 여부가 미확인이다. 해당 주제·UN 역할은 확인 전 확정하지 않는다. 검토 메타데이터는 등록부·분석 입력·후보 근거에 연결되어 있다.
- 영어 자료 안의 비영어 인사·인용 네 곳은 [기존 언어 예외 기록](language_exception_review.json)을 유지한다. 이것이 국가별 영어 원문 부재를 뜻하지는 않는다.
- 자동전사 원음 전체 검증과 모든 발언의 의미 검토는 완료하지 않았다. 원문의 ASR 정확성 표시를 보존한다.
- 임베딩·모델 분류·최종 보고서 실행은 아직 시작하지 않았다. 현재 GO는 데이터 구조·출처와 로컬 검색이 분석 착수에 적합하다는 판단이다.
