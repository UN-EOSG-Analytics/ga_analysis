# 분석 입력 준비 상태

분석 프로그램 준비 상태는 [전체 워크플로우 실행 안내](../../docs/ANALYSIS_WORKFLOW.md)를 따른다. 데이터 준비와 별도로 문맥 검토→임베딩→taxonomy→분류→집계→Word/PDF 생성이 구현·오프라인 검증되었다. 실제 DB 분석은 아직 실행 전이다.

최신 시작 판단: [분석 시작 GO 및 남은 조건](ANALYSIS_GO.md). 로컬 AI 유의어 후보 검색은 구현했으며 결과는 `output/screening/`에 있다. 문맥 판정·임베딩·분류는 별도 후속 단계다.

2025년 재투입 PDF 대조·정리: [검토 결과](pdf_2025_review.md). 영어 PDF 121개국을 비교 자료로 연결했으며, 세인트빈센트그레나딘의 PDF 추가 AI 문단은 실제 낭독 여부 확인 대상으로 분석 입력에 표시했다. 원문 전사 본문은 보존한다.

최신 확인: [DB 재점검 결과](db_review.md), [동료 검토용 공유 안내](PEER_REVIEW.md). 구조·해시·중복 오류는 없으나 비영어 구절 4곳과 입력 없는 국가–연도 42건은 별도로 표시했다.

**확정 원문 1,888개를 단일 분석 입력으로 준비했다.** 2019년 속기록과 2025·2026년 전사를 원문으로 확정했으며, 추가 국가별 PDF 확보를 기다리지 않는다. 2025년 마지막 날 전사도 반영했다.

## 바로 사용할 파일

국가별 주요 일반토의 발언은 해당 국가의 대표 입장으로 분석한다. 발언자 직급 분류·비교·가중치·정상 수 집계는 제외한다.

- 분석 입력: `output/pipeline/speeches.jsonl` — 공식 속기록 1,528개 + 자동전사 360개.
- 활성 등록부: `config/source_manifest.jsonl`.
- 국가별 추출본: `data/analysis_ready_en/YYYY/YYYY_ISO3.json`.
- [국가–연도별 확보 현황](country_year_coverage.csv), [실행 결과](release_status.json), [입력 무결성 결과](input_integrity.json).

## 형식 차이 처리

- 공식 PV는 페이지·열·발언자·부록을 기준으로, ASR JSON은 발언자 메타데이터로, ASR TXT는 발언자 표제와 줄 범위로 분리했다.
- 의장·사무총장·옵서버·답변권을 주요 회원국 연설에서 제외했다. 2026년 이집트 연설의 이름 없는 연속 구간 39단어도 본 연설에 연결했다.
- 원본 해시와 PDF 페이지·블록, JSON pointer·시간, TXT 줄·발언 시작 시각을 공통 구절까지 보존한다.
- 긴 전사 문단을 최대 350단어·3,000문자로 나눴다. 원래 본문과 순서를 보존하며 원문을 교정·요약하지 않는다.
- 국가–연도 중복 대표본, 원본 해시 변경, 잘못된 위치, 본문 누락·재배열, 최소 확보 건수 미달은 준비 단계에서 차단한다.

`accepted`는 분석 원문으로 선택했다는 뜻이다. 자동전사의 `source_type=automatic_transcript`와 정확성 미검토 표시는 유지한다. 모든 AI·주제 판정은 `Pending`이다.

## 남은 사항

1. **2026년 마지막 날 전사:** 미수집이며 해당 연도는 부분 자료로 표시한다.
2. **분석 단계:** AI 구절 문맥·근거 검토, 임베딩, 공통 taxonomy, 분류·집계·최종 보고서는 아직 실행하지 않았다. 자동전사 표현의 불확실성도 근거 검토에 표시한다.

## 재실행과 보관

```powershell
python -m unga_analysis prepare
python -m unga_analysis status
```

새 원본을 추가했을 때만 `prepare`를 재실행한다. 제출 PDF와의 대조는 필요할 때 근거 검토에 이용할 수 있으며, 분석 입력을 만드는 필수 단계에서는 제외했다.

기존 제출 PDF·중복 복사본·사용하지 않는 캐시·옛 감사표·수집/대조 스크립트는 [복구용 보관본](../../archive/README.md)에 정리했다. 원본 속기록과 현재 입력은 작업 폴더에 유지한다. 이전 분류 결과는 새 입력에 복사하지 않는다.
