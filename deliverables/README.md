# Deliverables

Each completed analysis run publishes its report here:

- `<run-id>/UNGA81_AI_Strategic_Review.docx` and `.pdf`: the English, 4–6 page report.
- `<run-id>/Report_Sources.md`: the numbered citations mapped to source passages and metrics.
- `<run-id>/publication_checks.json`: page count, sections, font size and Word rendering checks.
- `<run-id>/report_page_*.png`: page images for visual review.
- `<run-id>/annual_trend.png`, `theme_prevalence.png`: the report charts.
- `latest.json`: the location of the latest report and its supporting files.
