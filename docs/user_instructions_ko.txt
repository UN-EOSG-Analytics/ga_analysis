당신은 UN EOSG의 Strategic Planning and Monitoring Unit(SPMU)을 지원하는 데이터 사이언티스트이자 정책 분석가다. 로컬에 저장된 국가별 UN General Debate 연설 PDF를 분석하여, 아래 네 섹션으로 구성된 영어 4–6페이지 고위급 전략 보고서를 완성하라.
먼저 실제 자료 규모와 실행 환경을 점검하고, 비용·품질·처리시간을 비교하여 적절한 기술을 선택하라. 모든 PDF를 유료 API로 임베딩해야 한다고 미리 가정하지 마라. 방법론 탐색이나 계획 제안에서 멈추지 말고, 선택한 방법으로 분석·검증·보고서 작성까지 진행하라.
- 입력 폴더: [여기에 국가별 연설 PDF가 있는 로컬 폴더 경로 입력]
- 경로를 비워두었다면 현재 작업 폴더와 하위 폴더에서 자료를 찾는다. 자료가 없거나 여러 후보 중 대상을 구분할 수 없을 때만 경로를 질문한다. 관련 없는 개인 폴더까지 탐색하지 않는다.
- 대상 연도: 2026년 UNGA81을 중심으로, 가능한 경우 2017년 UNGA72부터 비교한다. 누락 연도는 확보 범위를 명시하고 분석한다.
- 핵심 데이터: 각국의 General Debate 주요 연설 전문. 다른 고위급 회의, 안보리, 연중 GA 회의, 답변권 발언, 진행 발언은 주요 집계에서 제외한다. SG·PGA·EU·옵서버 발언은 회원국 수치와 분리하고 필요하면 맥락 자료로 사용한다.
- 기본 단위: 국가–연도별 주요 연설 1건. 번역본·중복본·수정본은 대조하여 대표본을 정하고 원본은 보존한다. 해당 국가를 대표한 주요 일반토의 발언을 그 국가의 해당 연도 대표 입장으로 처리한다. 발언자 직급별 분류·비교·가중치·정상 수 집계는 하지 않는다.
- 같은 입력 폴더나 지정된 참고자료 폴더에 있는 300924 SPMU UNGA Summary.docx와 AI capacity-building/Global Fund 관련 문서는 참고한다. 없으면 있다고 가정하지 않는다. 이전 보고서는 문체·수준·범위의 참고자료이며, 기존 TF-IDF 방법을 그대로 반복할 필요는 없다.
- 2026년 일반토의가 종료되기 전에 작업하면 기준일과 부분 집계임을 표시한다. 알려진 초안 목표일은 2026년 9월 29일 화요일이다. 이후 실행한다면 실제 실행일과 확보 범위에 맞춘다.
국가·연도·날짜·언어·출처·페이지 수·텍스트 추출 상태를 목록화한다. 발언자 이름과 원문 소개는 국가 귀속 확인용으로만 보존한다. 파일명만 믿지 말고 본문으로 확인하며 확인 불가 항목은 표시한다. 제출 연설문, 공식 회의록, 자동 전사본을 구분한다. 국가별 PDF라고 해도 다른 행사나 여러 발언이 섞였는지 확인한다.
우선 로컬에서 텍스트를 추출하고 이미지형 또는 추출 실패 페이지에만 OCR을 적용한다. 제목·반복 머리말·단 편집 때문에 문장이 깨지는지 확인하고 원본 페이지 위치를 유지한다. 누락 국가를 자동으로 AI 미언급으로 처리하지 않는다. 가능한 공식 발언자 명단·일정과 대조하고, 국가별 완전성 확인이 안 된 연도는 그 한계를 남긴다.
실제 파일 수, 추출 텍스트량, 대략적인 토큰 수, 언어 분포, CPU/GPU·메모리와 설치된 도구를 확인한 뒤 다음 세 경로를 현실적으로 비교한다.
1. 키워드·어휘 검색으로 후보를 찾고 원문을 읽어 분류하는 최소 구성.
2. 로컬 임베딩 모델을 이용한 의미 검색·주제 탐색.
3. 호스팅 임베딩 API를 이용하는 구성.
최신 모델·가격은 해당 공급자와 프로젝트의 공식 문서로 확인한다. 확인할 수 없는 가격이나 실행 가능성을 만들지 않는다. 각 경로의 비용, 예상 시간, 언어 적합성, 의미 검색 품질과 관리 부담을 비교하되, 긴 기술 조사로 작업을 지연시키지 않는다. 임베딩 비용뿐 아니라 OCR·번역·LLM 분류·보고서 생성에 추가 비용이 발생하는지도 구분한다. 기존 계정 사용권이나 API 키가 있다는 사실만으로 유료 사용이 승인됐다고 판단하지 않는다.
서로 다른 연도·지역·언어의 소규모 표본에 AI 명시 발언, 유사 표현, AI와 무관한 디지털 발언, 제도에 대한 찬반 발언을 포함해 시험한다. 근거 문장을 읽어 결과를 검토하고 가장 단순하면서 충분한 품질의 경로 하나를 선택한다. 전체 문단 임베딩이 실제로 저렴하고 누락 방지에 유리하다면 선택해도 된다. 비용이 크면 넓은 후보 검색과 주변 문맥 추출 후 관련 문단만 임베딩한다. 이 경우 검색에서 탈락한 문단도 일부 점검하여 필터가 지나치게 좁지 않은지 확인한다.
새로운 유료 API 지출은 사용자가 예산을 승인한 경우에만 실행한다. 예산이 없으면 우선 추가 API 비용 없이 가능한 경로로 계속 진행한다. 유료 방식이 꼭 필요한 경우에만 예상 총비용·효과·대안을 제시하고 질문한다. 로컬 모델도 다운로드·메모리·실행시간 부담을 평가한다.
선택 결과는 한국어로 한 번 간단히 알리고, 승인된 범위 안에서 계속 실행한다. 기본 분석 설계는 아래의 Discover → Classify → Aggregate 순서로 고정한다. 기술 비교는 주로 임베딩 모델·실행 환경·비용과 분류 품질을 선택하기 위한 것이며, K-means·DBSCAN·HDBSCAN·Leiden 등을 모두 시험하는 벤치마크로 확대하지 않는다. TF-IDF는 탐색 군집을 설명할 대표 단어를 뽑는 보조 용도로만 사용한다. 방법론 메모에 실제 선택·실행한 방법과 선택 이유를 남긴다.
- 키워드 집계와 의미 분석은 역할을 나눈다. 검색 결과나 임베딩 유사도만으로 최종 언급·지지 수치를 확정하지 않는다.
- AI 탐지 사전에는 artificial intelligence, AI/A.I., machine intelligence, machine learning, generative AI 등 실제 자료에서 확인되는 변형을 포함한다. 다른 언어에는 대응 표현을 적용한다. 검색 범위는 넓게 잡되, digital·algorithm·data·compute·autonomous weapons 등의 단어만으로 AI 언급을 확정하지 않는다. 명시적 AI 언급과 문맥상 관련된 넓은 논의를 구분한다.
- AI 관련 문단과 필요한 앞뒤 문맥을 분석한다. 임베딩을 쓰면 가능한 한 동일 모델·전처리 기준을 전 기간에 적용한다. 한 연설의 반복 문구 때문에 국가별 비중이 커지지 않도록 한다.
- 주제는 데이터에서 발견한다. 임베딩 군집은 주제 후보를 만드는 도구이며, 원문을 검토해 주제 정의와 포함·제외 기준을 확정한다. 한 문단에 복수 주제를 허용하고, 미분류·소수 의견도 검토한다. 모든 문단을 억지로 하나의 군집에 넣지 않는다.
- 연도별 주제 변화는 공통된 주제 정의로 비교한다. 독립적으로 생성한 연도별 군집 번호나 유사도 점수를 그대로 비교하지 않는다. 올해의 관심사를 과거 발언에 소급해 강제로 적용하지 않는다.
- 모든 핵심 수치·주제·입장·인용은 국가·연도·원문 구절·PDF 파일·페이지로 추적 가능해야 한다. 의미가 비슷하다고 입장도 같다고 판단하지 않는다.
- 집계에 포함한 AI 발언과 모든 제도적 제안은 원문으로 확인한다. 자동 분류는 잠정치로 남기고 검토 여부를 기록한다. 가능하면 표본을 독립된 두 번째 검토 절차로 확인한다. 같은 모델을 다시 실행한 것을 사람 간 일치도로 보고하지 않는다. 별도의 검증 자료 없이 탐지율 X%, 정확도, κ 등을 만들지 않는다.
- 연도별 출처·언어·자료 확보율 차이가 추세에 미치는 영향을 검토한다. PDF 추출 오류나 전사 오류를 정책적 차이로 해석하지 않는다. 문맥상 불확실한 사례는 별도로 남긴다.
Keyword dictionary + 문맥 검토 → AI 관련 semantic chunks → Sentence embeddings → Agglomerative Hierarchical Clustering → 대표 문단과 TF-IDF 특징어 검토 → 주제 분류 체계(taxonomy) 확정.
- 군집화 단위는 국가 전체가 아니라 AI 관련 의미 단위다. 문장 경계와 문맥을 보존하고, 겹치는 청크가 같은 근거를 중복 생성하지 않도록 원문 위치로 연결한다.
- 계층적 군집화의 기본 설정은 cosine distance + average linkage로 한다. Ward linkage에 cosine distance를 결합하지 않는다. 실제 데이터 규모에 따른 메모리·시간을 확인한다. 대규모라 전체 탐색이 어렵다면 연도·지역과 국가별 기여량을 고려한 탐색 표본을 사용하고, 최종 분류는 전체 대상에 적용한다.
- 군집 수를 미리 6개로 고정하지 않는다. 소수의 절단 수준을 비교하고 대표·경계 문단을 검토하여 해석 가능한 주제를 정한다. 군집은 알고리즘·모델·거리·절단 기준에 영향을 받는 탐색 결과이지, 유일한 자연적 정답이 아니다.
- TF-IDF는 같은 전처리와 어휘 공간에서 계산하고 군집별 특징어를 추출하여 이름 붙이기를 보조한다. 특징어 점수를 국가 수, 지지 강도 또는 중요성으로 해석하지 않는다.
- Security/risks, Global governance, Development/SDGs, Digital divide/capacity building, Human rights/ethics, Innovation/economic opportunities는 예시다. 실제 결과를 이 여섯 가지에 억지로 맞추지 않는다. 특히 군사·안보와 기술적 AI safety는 필요하면 하위 주제로 구분한다.
- 올해와 과거의 자료를 점검해 공통 주제 정의를 만들고, 특정 연도·장문 연설이 주제 발견을 지배하지 않도록 한다. taxonomy에는 정의, 포함·제외 기준, 예시, 경계 사례를 기록한다. 새 주제를 추가하면 비교 대상 전체에 같은 기준으로 재적용한다.
확정 taxonomy → 각 AI 청크에 모든 주제를 독립적으로 판정 → 근거 문장 검토 → 최종 multi-label classification.
- 최종 분류는 탐색 군집 소속을 그대로 복사하지 않는다. 각 청크가 Security, Governance, Development 등의 각 정의에 부합하는지 개별 판정하여 여러 주제에 동시에 속할 수 있게 한다.
- 기본 구현은 명시적인 taxonomy를 이용한 LLM 보조 분류와 원문 검토다. 승인된 도구·예산에 맞게 실행하고, 별도의 유료 분류 API가 없으면 Codex가 청크를 나누어 읽고 근거와 함께 분류한다. 임베딩 유사도는 분류 후보를 찾는 데 사용할 수 있지만 최종 Yes/No 기준으로 단독 사용하지 않는다. 실제로 LLM을 썼다면 모델·프롬프트·검토 절차를 기록한다.
- 청크별 주제값은 Yes / No / Uncertain로 저장하고 근거 파일·페이지·구절을 연결한다. 분류 전 항목이나 불확실한 항목을 No로 채우지 않는다. 집계 전 모호한 사례를 검토하고 해결되지 않으면 수량과 영향을 표시한다.
- 주제 언급 여부와 정책적 입장은 별도 필드다. 예를 들어 governance 주제를 말했어도 특정 UN 기구 지지를 뜻하지 않는다.
문단별 복수 주제 결과 → 국가–연도별 OR 집계 → Country × Theme matrix → 주제별 비율과 co-occurrence.
- 같은 국가가 한 주제를 여러 번 말해도 해당 국가–연도에서는 1회만 센다. 한 개 이상의 검증된 청크가 Yes이면 그 국가–연도 주제값은 1이다. 모든 대상 청크를 검토한 뒤 해당 근거가 없으면 0, 자료·분류가 불완전하면 NA로 둔다.
- 보고서의 비율은 클러스터 비율이 아니라 AI 언급 국가 중 각 주제를 언급한 국가의 비율이다. 같은 연도에서 분석 가능한 AI 언급 국가 수를 N, A 주제 언급 국가 수를 n(A)라 하면 주제 비율은 n(A)/N이다. N과 미확보·불확실 사례를 공개한다. 복수 주제이므로 주제 비율 합은 100%를 넘을 수 있다.
- 공동 언급 국가 수 n(A∩B)를 계산한다. A를 언급한 국가 중 B도 언급한 비율은 n(A∩B)/n(A)다. 역방향 n(A∩B)/n(B)와 구분하며 분모가 0이면 NA로 표시한다. 같은 연도·동일한 검토 대상 안에서 비교한다.
- 모든 비율은 가능한 경우 n/N과 함께 제시한다. 표본이 작은 조합을 과장하지 않는다. 특정 조합이 특별히 강하다고 말하려면 전체의 B 언급 비율 n(B)/N과 비교한다. 단순히 흔한 주제가 자주 겹치는 것을 특별한 연관으로 해석하지 않는다.
- 기본 co-occurrence 단위는 같은 국가의 같은 해 주요 연설이다. 다른 문단에서 두 주제를 언급해도 포함된다. 이를 같은 문장에서 두 주제를 연결했다거나 인과관계·공동 입장·정치적 동맹이 있다는 증거로 해석하지 않는다. 실제 연결 논리를 논할 때는 해당 원문을 추가로 확인한다.
- Themes 본문에는 주제별 국가 비율 막대그래프와 의미 있는 공동 언급 결과 1–2개를 우선한다. 전체 국가×주제 표와 공동 언급 표는 별도 근거 파일에 둔다. 페이지가 부족하면 기존 표·차트를 교체해 4–6페이지를 유지한다.
- 가능하다면 같은 taxonomy로 연도별 주제 비율을 비교한다. 국가 구성이 달라진 영향과 같은 국가의 의제 변화는 구분하며, 현재 자료가 부분 집계이면 잠정 결과로 표시한다.
방법: 키워드 사전과 변형 표현 검색 → 원문 확인 → 국가·연도별 중복 제거.
보여줄 내용:
- 올해 AI를 언급한 국가 수와 검토한 대상 국가 연설 대비 비율. 발언자 직급과 관계없이 국가–연도별 한 번 집계한다.
- 지역별 언급 국가 수와 각 지역의 검토 대상 연설 대비 비율. UN 지리 분류를 일관되게 쓰고 분류 기준을 명시한다.
- 가능한 경우 2017년부터의 연도별 언급 수·비율과 자료 확보 범위. 193을 일률적인 분모로 쓰지 않는다.
- 시각자료는 연도별 추세 그래프 1개와 올해 지역별 간단한 표를 우선한다. 올해가 부분 집계라면 명확히 표시한다.
방법: Sentence embeddings + Agglomerative Hierarchical Clustering으로 탐색 → taxonomy 확정 → 문단별 multi-label 분류 → 국가–연도별 주제 행렬과 공동 언급 분석. 최종 수치는 군집 크기에서 산출하지 않는다.
보여줄 내용:
- 올해 실제로 중요한 주제를 약 4–6개로 압축해 제시한다. 이는 본문의 편집 목표이며 분석 주제 수를 강제로 고정하는 기준이 아니다. 안전·검증, 역량·재원, 데이터·주권, 인권, 경제·개발, 평화·안보 등은 후보이며 결론을 미리 정하지 않는다.
- 각 주제의 핵심 발견, 이를 제기한 국가·지역의 차이, 짧은 대표 인용 또는 정확한 의역.
- 자료가 뒷받침하면 연도별 강조점 변화. 주제별 비율의 분모가 전체 연설인지 AI 언급 연설인지 명시한다.
- 빈도가 낮아도 전략적으로 중요한 새로운 제안·우려는 포함한다. 결과를 보기 전에 “안전에서 개발로 이동했다” 같은 서사를 확정하지 않는다.
방법: 특정 메커니즘·제도 모델의 근거 문장을 추출하고, 원문으로 입장과 요구 기능을 분류한다. 명칭 검색과 의미 검색을 함께 활용할 수 있다.
집중 대상:
1. Global Dialogue on AI Governance.
2. Independent International Scientific Panel on AI.
3. Global Fund for AI Capacity Development. Global Fund for AI, AI Capacity-Building 등 실제 사용된 명칭 변형도 추적한다.
4. FSB/Financial Stability Board, IAEA/International Atomic Energy Agency를 본뜬 AI 모델. IPCC, CERN, 신규 국제기구·검증체계 등 다른 모델이 실제 제안되면 포함한다.
보여줄 내용:
- 누가 무엇을 언급했고, 단순 언급·환영·지지·구체적 행동 요구·조건/우려·반대·실제 기여 약속 중 어디에 해당하는가.
- UN에 대화, 과학적 평가, 역량 지원, 재원, 규칙·표준, 감독·검증 등 어떤 기능을 기대하는가.
- UN의 역할을 명시적으로 요구한 발언과 일반적인 국제협력 요구를 구분한다. AI와 무관한 IAEA·FSB 언급은 제외한다.
- 주요 모델은 제안국 / 기대 기능 / 근거 발언의 간단한 표로 제시한다.
- UN 외의 국제적 노력이 연설에서 중요하게 등장하면 UN과의 관계를 분석하되, 연설에 없는 의제를 본문에 과도하게 추가하지 않는다.
방법: 확인된 발언·국가별 요구를 기관의 현재 역할과 대조하여 전략적 시사점을 도출한다.
보여줄 내용:
- UN 전체와 SPMU: 정치적 공감대, 주요 입장 차이, SG 차원의 메시지·후속 관여 우선순위.

국가의 실제 요구와 분석자의 권고를 분리한다. 일반적인 역량 강화 요구를 Fund 지지나 공여 약속으로 바꾸지 않는다. 제도 현황과 권한은 최신 공식 UN 문서로 확인하고 연설 데이터와 배경 문서를 구분한다. 사용자가 준 초안은 초안으로 취급하고, 최신 승인본과 내용이 다르면 차이를 기록한다.
